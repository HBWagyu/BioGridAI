# Farmer guide (simulation)

1. Start `make ui`.
2. Open **05:30 Briefing** and run planning.
3. Open **Live Map** — orange leaf marker is Whiplash (vendor), red cog is Optimus.
4. Open **HITL Queue**. Approving the Thermobrain item simulates a cut.
5. Open **Traceability** and confirm the chain verifies.
6. **Settings** can disable the Noumenal adapter without touching Tesla core clients.
